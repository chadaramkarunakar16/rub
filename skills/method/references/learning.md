# Learning resources by topic

Use these for the "What to learn" section. Prefer free, current material. Check that a link
still works before putting it in a report.

| Topic | Why it matters | Free resource |
| --- | --- | --- |
| HTTP, APIs, REST | Every feature talks to a backend | MDN Web Docs: "An overview of HTTP" |
| JavaScript / TypeScript | Language of most web stacks | javascript.info; TypeScript Handbook |
| React + Next.js | Frontend and API routes in one project | react.dev "Learn"; Next.js "Learn" course |
| SQL and Postgres | Where most product data lives | Supabase docs; "Select Star SQL" |
| Data modelling | Getting tables and relations right early | Supabase "Database design" guides |
| Caching and Redis | Speed for feeds, sessions, rate limits | Redis University (free courses) |
| WebSockets and realtime | Live cursors, chat, presence | MDN "WebSockets API"; Supabase Realtime docs |
| CRDTs and collaboration | Multiplayer editing | Yjs docs; "CRDTs: The Hard Parts" talk (Martin Kleppmann) |
| Queues and background jobs | Emails, video processing, retries | Inngest docs; BullMQ docs |
| Search | Fast relevant lookup | Meilisearch docs; Postgres full-text docs |
| Embeddings and RAG | AI memory and semantic search | Anthropic and OpenAI cookbooks; pgvector README |
| Payments | Charging safely | Razorpay docs (webhooks, idempotency); Stripe docs |
| Video delivery | Upload, transcode, stream | Mux docs; Cloudflare Stream docs |
| System design basics | Seeing the whole picture | "System Design Primer" (GitHub) ; "Designing Data-Intensive Applications" (book) |
| Deployment | Shipping it | Vercel docs; Railway docs; Docker "Get started" |
